## Adaptation mobile
Sous 761 px : une colonne, titres fluides, textes et zones tactiles agrandis, portraits sans cadre et images réduites proportionnellement si nécessaire. Sous 1001 px, les images sont limitées à leur colonne, y compris si des dimensions sont inscrites dans le HTML. Sur grand écran, leurs dimensions initiales restent conservées. Les zones vides disparaissent sur mobile. Aucun défilement horizontal ne doit être nécessaire pour lire le contenu.
